## 6. Central thesis and technical treatment

This section supplies the requested technical handoff without treating the
handbook as a normative design change.

| Topic | Treatment and boundary |
|---|---|
| Central proposition | Construct PIT state, forecast defined outcomes, measure incremental value and improve through governed correction. Challenge the need for complexity: direct controls can win and LFDE may be rejected. |
| Six distinctions | Observation ≠ state; state ≠ forecast; forecast ≠ decision; learning ≠ live self-rewriting; latent ≠ magic; complexity ≠ intelligence. |
| Market Tensor | Asset/context × time × channel; separate resolutions, observation/padding/artificial masks, train-only normalization, calendars, corporate actions, availability clocks, ordering and fingerprints. Asset order is not image geometry. |
| No screenshot path | Inputs are structured PIT values, with governed narrative and graph branches. CV-inspired masking/patching is a method, not chart-image classification. |
| K/Z/X | Disclosed K transform, pinned learned Z, quality envelope Q and typed X. A random Y, forecast distribution P_hat and realized Y* are explicitly different objects. Initial deterministic state is not automatically a posterior. |
| LFDE | Qualification, optional bounded offline fit, versioned latent snapshots, uncertainty semantics, contribution/stability tests and rejection. No arbitrary acquisition, economic coordinate naming or live model replacement. |
| Candidate methods | Explicit/classical controls, PCA and a relevant PPCA/dynamic control; one small masked temporal patch encoder first. AE, contrastive, TCN, Transformer, selective SSM and graph alternatives have separate hypotheses and gates. |
| Market Intelligence | Separate N representation, dated source/cutoff/provenance, novelty, supported direction, scope, quality and uncertainty. Repetition is not independent corroboration; raw text is not dumped into the numeric tensor. |
| Graphs | Dated typed explicit versus learned edges; sector, supply-chain, correlation, lead/lag, exposure and event relationships. Learned association is not causality. Later complexity must survive ablation/cost checks. |
| Multi-horizon | Preserve short pullback, daily strength and longer context without majority voting or inventing new calibrated probability horizons. Per-branch validity and staleness remain explicit. |
| State estimation | Deterministic assembly versus learned fusion versus probabilistic filtering; typed uncertainty does not prove a calibrated posterior. Missing bound branches cause explicit absence/abstention, not silent composition substitution. |
| State dynamics | Filter at cutoff, project forward under declared assumptions, integrate unknown future state. Compare persistence/linear dynamics and a bounded HMM against the same-state direct head. No future smoothing as a decision-time feature. |
| Forecast heads | Initial strict next-session equity endpoint; later return distribution/volatility/path-risk heads only after their own target, horizon, label, loss, calibration and admission gates. No generic success probability or option PoP. |
| Latent evaluation | K, Z, K+Z under comparable fit/search budgets, paired populations and proper losses; calibration, coverage, regimes, stability, redundancy, dimensions, seeds and costs. Positive Δ_Z alone is not acceptance. |
| Ablation | Full versus minus sector/narrative/derivatives/latent temporal/graph/macro, only for admitted branches. Total-family removal cuts every route and refits affected stages; inference occlusion is a different experiment. |
| Stability | Rotations/reordering versus genuine degradation; eligible anchor protocols, Procrustes/CCA/CKA/principal-angle concepts, probes and seed/window/regime checks. Pin encoder/basis/head; never overwrite vectors to improve a plot. |
| Latent-to-explicit | Reproducible association → probe → economic hypothesis → specified deterministic factor → independent PIT evidence → optional review. No automatic semantic naming or modification of frozen A2. |
| Uncertainty | Separate estimate uncertainty, sampling/model assumptions, freshness, data quality, provenance, regime membership and forecast calibration. NOT_ESTIMATED is honest; multiplying disparate scores does not create probability. |
| Self-correction | Frozen forecast → later outcome → independent diagnostics → authorized candidate → validation → prospective shadow → explicit future COLD approval. No autonomous promotion, HOT swaps or historical rewrite. |
| Self-diagnosis | Suspected data integrity, explicit/latent state, regime, dynamics/head, calibration, scope/event and inconclusive causes. A wrong outcome does not establish a causal diagnosis. |
| Timescales | Fast calibration/abstention; medium weights/routing; slow representation/family/factor changes. These are governance classes, not schedules or exemptions from review. |
| Replay | Recorded read, exact compatible recomputation and newly identified counterfactual are distinct. Pin data/tensor/factor/latent/basis/fusion/dynamics/head/calibrator/policy and fit/execution lineage. Missing exact dependencies are unverifiable, not permission to substitute current models. |
| Monte Carlo / ensemble | Monte Carlo integrates a qualified path model, not votes. Marginal direction/volatility heads do not create a joint path law. Combine only independently qualified compatible members; static controls precede learned weights/MoE, with separately tested missing-member behavior. |
| Tunability / pluggability | Separate invariants, trusted COLD profiles, experiments, immutable model artifacts, scoped requests and future proposals. No request-controlled loader URLs, fitting budgets, active weights or authority. Optional dependencies remain isolated. |
| Scientific failure | Invalid, inconclusive, non-contributing, unstable, miscalibrated, over-budget and failed-shadow results remain visible. Controls survive; sophistication has no entitlement to survive. |
| Roadmap | FM-0 control → FM-1 explicit state → FM-2 bounded LFDE → FM-3 dynamics → FM-4 heads → FM-5 modalities/graph → FM-6 ensemble/correction expansion. Nested LFDE sequence is explained; progress may stop at every stage. |
| A7 seam | Proposed Forecasting/FM, independent Evaluation and Governed Learning remain separate owners. A7 has not been rewritten, accepted or implemented; A4/A5/A6 and TM/broker boundaries stay intact. |
| Paper 1 | Established factor, multimodal-finance, representation and governance prior art is acknowledged. A potentially useful TI integration is not a proven new algorithm or first-system claim. Reconciliation and a focused novelty audit precede manuscript readiness. |
| Paper 2 | Qualified permitted PIT data, preregistered protocols/trials, controls, ablations, untouched tests, uncertainty/calibration/stability/coverage/cost evidence and prospective shadow. Null/failed results retained; neither paper nor experiment produced here. |
