# POST_A3_PRE_A4_LOCAL_FACADE

## Status and scope

This milestone adds a narrow, same-process Python application boundary in
`tiaf.facade`. It composes already accepted deterministic and captured-input TI
capabilities without changing their domain semantics. The facade owns trusted
startup configuration, caller admission, lifecycle, bounded artifact access,
operation-specific dispatch, and safe results/errors.

It is not an HTTP/gRPC service, universal dispatcher, provider registry, replay
engine, model gateway, Shell, database, queue, or execution path. No live
capability is exposed. The original facade milestone stopped before A4; the
later A4.1 slice adds one bounded deterministic operation without changing
these hosting and authority boundaries.

## Public surface

The catalog is an explicitly authored immutable tuple. Descriptors contain no
callables and are not generated by reflection.

| Capability | Interface | Effect | Replay | Meaning |
| --- | --- | --- | --- | --- |
| `baseline.assess` | `PUBLIC` | `PURE` | deterministic | Existing A2 assessment over caller-supplied typed evidence |
| `opportunity.assemble` | `PUBLIC` | `CAPTURED_READ` | deterministic | Existing A3.9 assembly from an authorized A3.8 capture |
| `a4_input.project` | `PUBLIC` | `CAPTURED_READ` | deterministic | Existing pre-A4 semantic projection from an authorized build input |
| `a4.evaluate` | `PUBLIC` | `CAPTURED_READ` | deterministic | A4.1 challenge/arbitration over one authorized captured semantic projection |
| `replay.recorded` | `PUBLIC` | `CAPTURED_READ` | recorded | Bounded reconstruction of an authorized A3 package or foundation capture |
| `capabilities.list` | `PUBLIC` | `PURE` | none | Permission-filtered safe descriptor discovery |
| `replay.verify` | `ENGINEERING` | `CAPTURED_READ` | deterministic | Verification of an authorized A3 replay package |

Every descriptor independently identifies capability version `1.0`, request and
result schema IDs/versions, interface level, effect, determinism/model support,
replay support, authority scope, cost knowledge, availability, and deprecation
metadata. Capability version is separate from package version `0.1.0`, A0
contract schema `1.0`, child domain schemas, policy versions, capture formats,
and any future transport version. A breaking capability meaning requires a new
capability version.

`opportunity.orchestrate` is deliberately deferred. Its accepted A3.8 path can
perform controlled live acquisition and privileged composition; this facade
slice has no accepted live-effect lifecycle/admission contract. Exposing it as a
captured operation would misstate its meaning. `trace.inspect` is also deferred
until one mature, redacted, unified trace projection exists. Neither omission is
filled by generic dispatch.

## Trusted composition and admission

`TrustedFacadeConfig` is supplied by the embedding application/operator, never
constructed from natural-language or ordinary invocation fields. It contains
operator policy, caller grants, logical startup artifacts, one artifact-root
identity, and an enforced single-writer marker. The owner validates a serialized
copy, constructs its private artifact store and accepted engine objects, freezes
artifact composition on `start()`, and rejects new work after `shutdown()`.
Consumers receive only a caller-bound `LocalFacadeClient`; they do not receive
the artifact store, registries, providers, routers, services, policies, or broker
handles.

Effective admission is the intersection of:

- the capability's declared authority/effect/interface;
- caller and operator capability allow-lists;
- caller and operator authority scopes and authority references;
- caller and operator profile allow-lists;
- caller/operator engineering, live, and model flags;
- caller/operator data entitlements; and
- requested, caller-ceiling, and operator-ceiling budgets.

Profiles select permitted depth; they grant no authority. Catalog visibility is
filtered by the same trusted inputs but never grants invocation. Revocation is
checked at invocation admission and again before artifact access. Requests have
no fields with which to self-grant engineering, live, model, entitlement, or
budget authority.

## Invocation lifecycle and contracts

Shared `InvocationScope` carries request/correlation identity, subject,
objective, horizon, `as_of`, profile and authority references, bounded requested
budget, optional position-context identity, and admitted logical artifact refs.
Each operation has a separate typed request and result. Result metadata records
the capability version/effect, opaque run and budget identities, policy/model/
operator references, admitted artifacts, gaps/warnings, zero-safe usage, and
created/start/end timestamps.

All timestamps remain aware and normalize through the canonical
`Asia/Kolkata` contract policy. There is no global mutable current-request
object. Each call obtains its own admission, run identity, scope and usage. Pure
calls may execute concurrently; this milestone makes no multi-process safety
claim. Startup composition is immutable for all admitted work. There are no
`LIVE_READ` operations, and the initial host policy remains one top-level live
call at a time when a future live capability is separately accepted.

## Controlled capability composition

- `baseline.assess` delegates to `BaselineEngine.assess`; it neither acquires
  evidence nor reimplements A2 scoring.
- `opportunity.assemble` validates and reads one authorized A3.8 capture, then
  uses A3.9 `request_from_capture` and `assemble_opportunity_intelligence`. It
  returns structured intelligence and fingerprints, not the captured JSON.
- `a4_input.project` reads one authorized foundation build input and delegates
  to `build_projection`. It emits no A4 disposition.
- `a4.evaluate` reads one authorized foundation capture, validates/replays its
  projection and delegates to the A4.1 deterministic evaluator. Callers cannot
  inject a policy; it returns the safe A4 result and run fingerprint with zero
  external usage.
- `replay.recorded` distinguishes A3 recorded reconstruction from foundation
  recorded reconstruction and never repairs missing data live.
- `replay.verify` delegates to the accepted A3 verification path and requires
  an engineering grant.

All composed work is deterministic/no-model in this catalog. Usage therefore
records zero provider/tool/model calls, zero tokens, and zero cost units with
`KNOWN_ZERO` cost knowledge.

## Artifact, security, and error boundary

Artifacts are installed only by the trusted owner and addressed by qualified
logical IDs. Their exact checksum, JSON form, secret-bearing keys, typed artifact
kind, and existing capture/package integrity are checked before startup is
frozen. Caller input cannot contain arbitrary filesystem paths, URLs, secrets,
provider/router/registry objects, policies, functions, or modules. Reads require
the reference to appear in the invocation scope and recheck effective authority
and entitlement.

The private in-memory artifact map is a bounded implementation of the approved
local filesystem/corpus boundary; it does not expose paths and adds no database.
The owner/configuration remains responsible for the single-writer/root
assumption. A future durable implementation must preserve these logical-ref and
permission rules.

Errors are projected as immutable, serializable `FacadeErrorRecord` values using
the closed vocabulary `INVALID_REQUEST`, `UNSUPPORTED`, `PERMISSION_DENIED`,
`BUDGET_EXCEEDED`, `MODEL_DISABLED`, `UNAVAILABLE`, `FAILED`, and
`REPLAY_INTEGRITY_ERROR`. Internal payloads and object graphs are not included.
Domain outcomes such as `NO_TRADE`, `WAIT`, `CONFLICTED`, `ABSTAIN`, and
insufficient evidence are not facade failures. Optional source absence remains
a typed projection gap.

## Explicit non-capabilities

The facade adds no model/provider adapter, network dependency, dynamic plugin,
HTTP/gRPC endpoint, cloud service, queue, database, background worker, shell,
browser, SQL, broker/order authority, or A5-A7 behavior. Its A4.1 operation is
captured-read and deterministic only: no evidence acquisition, optional model
lane or trade expression is exposed. Replay remains usable with provider/model/
network unavailable and credentials absent. Frozen A2/A3 and foundation
semantics remain unchanged.
